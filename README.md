# please-finish-this-game

This is the source code of a game I made for Brackeys Game Jam 2025.1
The game is a platformer with some secret feature that you have to discover
[https://masstermax.itch.io/paperwork](https://masstermax.itch.io/please-finish-this-game)

The game was ranked 169th out of 2192 entries, and also ranked 44th in "Theme" criteria
All code was implemented by myself in Unity, all images were drawn in Aseprite by me. I used some free audio and a font from google fonts:
